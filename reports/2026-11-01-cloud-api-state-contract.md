# GAGARIN execution log — 2026-11-01

## One concrete improvement
Correct the Cloud API projection so it does not turn a missing decision into a user-facing `WAIT`, and so each ranking row carries separate `BIAS`, `SETUP`, and `TRADE PAPER` states.

## Finding
On the default `main` branch, `cloud_api.py` used `WAIT` as the fallback for missing decision objects in both the normal monitor path and Sputnik confirmation path. The JSON row exposed only `direction` and `action`, so supported preliminary direction could be obscured and the API did not expose the canonical state contract.

## Implemented
- Added `engine/cloud_api_status.py` as a display-only adapter.
- Missing decision -> `NO_DECISION`; legacy `WAIT` -> `PAPER_WATCH`.
- Preserve supported LONG/SHORT from the canonical decision-status helper.
- Expose `bias`, `bias_source`, `setup`, `trade_paper`, and `blockers` in Cloud API rows.
- Require live/data flags, explicit `fresh_live`, finite positive price and ATR, and a parseable timestamp inside the configured freshness window for `EARLY_SETUP`.
- Only a fresh, directional `PAPER_ENTRY` remains `CONFIRMED / ENTRY_AUTHORIZED_PAPER_ONLY`; stale/inconsistent PAPER_ENTRY is downgraded to `PAPER_WATCH`.
- No prices, entry, SL, TP, sizing, broker calls, or Telegram messages are generated by this adapter.
